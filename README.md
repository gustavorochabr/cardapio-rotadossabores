# Rota dos Sabores

Cardápio virtual mobile-first para seleção de itens e envio do pedido pelo WhatsApp.

O direcionamento de produto está em [docs/CONTEXTO_DO_PRODUTO.md](docs/CONTEXTO_DO_PRODUTO.md).

A linguagem visual e os padrões de interface estão em [docs/DESIGN_SYSTEM.md](docs/DESIGN_SYSTEM.md).

## Executar o aplicativo

```bash
npm install
npm run dev
```

O cardápio inclui busca, categorias, personalização, sacola persistente, entrega/retirada, revisão e envio do pedido pelo WhatsApp.
